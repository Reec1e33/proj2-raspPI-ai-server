# Security policy

Only 2.0.x gets fixes. The 1.x prototype is gone and isn't supported.

Please don't open a public issue for a vulnerability. Use the
[private report form](https://github.com/Reec1e33/proj2-raspPI-ai-server/security/advisories/new)
instead (Security tab, then "Report a vulnerability"). Tell me which component
and file, how to reproduce it, and what it lets you do. Leave out real API keys
and passwords. I'll reply in the advisory.

The threat model, the controls and the known gaps are in
[docs/security.md](docs/security.md).
