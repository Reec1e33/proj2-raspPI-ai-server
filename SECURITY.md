# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 2.0.x | Yes |
| 1.x (prototype) | No |

## Report a vulnerability

Do not open a public issue for a vulnerability.

1. Open the [private vulnerability report form](https://github.com/Reec1e33/proj2-raspPI-ai-server/security/advisories/new)
   of this repository. You can also open the **Security** tab and select
   **Report a vulnerability**.
2. Give the component and the file, the steps to reproduce the problem, and the
   effect.
3. Do not include real secrets, for example API keys or passwords.

The maintainer answers in the advisory.
